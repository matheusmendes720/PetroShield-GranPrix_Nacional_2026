# Project Rules and Agent Skills: Grand Prix SENAI 2026

## Objective
Establish the guidelines, agent skills, and rules necessary for the elicitation of technical specifications, planning, and successful participation in the Grand Prix SENAI 2026 Hackathon.

## 1. Project Scope & Roles (Escuderia)

The team (Escuderia) must consist of 4 to 5 members. Each member should take on specific roles to maximize efficiency and cover all hackathon requirements:

1.  **Product Owner / Strategist:** Responsible for the vision, pitch deck, and ensuring the solution strictly adheres to the challenge theme (acessibilidade, cibersegurança, automação, sustentabilidade).
2.  **Tech Lead / Architect:** Designs the system architecture, selects the tech stack, and ensures the technical viability and scalability of the prototype.
3.  **Frontend / UI/UX Developer:** Focuses on the user interface, user experience, and visual presentation of the prototype (following any defined style guides).
4.  **Backend / Data Engineer:** Develops the core logic, API integrations, database management, and any data analytics (BI) required.
5.  **QA / Pitch Master (Optional 5th member):** Ensures the prototype works flawlessly, conducts testing, and refines the final presentation and pitch delivery.

## 2. Agent Skills Required

To effectively support this project, the AI agents must possess the following skills:

### Technical Skills
- **`system-architecture`:** Ability to design scalable and robust system architectures (e.g., microservices, serverless) tailored for rapid prototyping.
- **`fullstack-development`:** Proficiency in modern web frameworks (e.g., Next.js, React, Node.js, Python/FastAPI) to quickly build functional prototypes.
- **`data-engineering-bi`:** Skills in structuring databases, creating scraping pipelines (if needed), and generating Business Intelligence dashboards for market analysis or solution validation.
- **`devops-rapid-deployment`:** Knowledge of quick deployment strategies (e.g., Vercel, Netlify, Docker, AWS/GCP basic services) to get the prototype live for judges.

### Strategic & Planning Skills
- **`product-management`:** Ability to apply Design Thinking and Lean Canvas methodologies to define the MVP (Minimum Viable Product).
- **`competitive-analysis`:** Skills to analyze market trends, competitors, and validate the innovative aspect of the proposed solution.
- **`pitch-deck-creation`:** Expertise in structuring compelling narratives for pitches, focusing on the problem, solution, market size, and business model.

## 3. Workflow & Timeline Rules

The project execution must strictly follow the hackathon timeline:

*   **Ideation Phase (Pre-Hackathon):** Focus on brainstoming within the themes (acessibilidade, tecnologia com valor real, cibersegurança, automação e sustentabilidade).
*   **Capacitation Alignment (April 6-10):** Integrate learnings from the official live sessions (Design Thinking, Analytical Thinking, Prototyping, Lean Canvas, Pitch) directly into the project plan.
*   **Execution Sprints (April 13-17):**
    *   *Day 1-2:* Finalize architecture, setup infrastructure, and build core backend/APIs.
    *   *Day 3-4:* Develop frontend, integrate with backend, and refine UX.
    *   *Day 5:* Final testing, bug fixing, recording the pitch video, and preparing submission materials.

## 4. Quality & Compliance Guards

*   **`compliance-guard`:** Ensure all deliverables meet the requirements specified in the official "REGULAMENTO GP SENAI 2026.pdf" (e.g., team size, submission formats, deadlines).
*   **`styles-guard`:** If a specific UI/UX theme is chosen, all frontend components must strictly adhere to the established design tokens to ensure a professional and cohesive prototype.
*   **`feasibility-check`:** Continuously evaluate if the proposed features can realistically be implemented within the 5-day hackathon timeframe. Prioritize core MVP features over "nice-to-have" additions.
