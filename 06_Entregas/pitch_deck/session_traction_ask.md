## 🎯 Contexto desta session

Esta é a **última session do pitch**. Em ~30 segundos, ela precisa:

1. **Provar tração** (Petrobras anchor + mercado endereçável)
2. **Validar viabilidade econômica** (ROI + pricing defensável enterprise)
3. **Criar urgência temporal** (window of exposure shrinking)
4. **Conectar com o ASK concreto** (Piloto 90 dias, baixo-âncimo, acionável)

**Atenção à estrutura:** o usuário (defendeu explícito) explicitamente colocou a **Viability (técnica + econômica) ANTES do CTA**. Esta session reflete essa ordem.

## 🎯 Por que esta session funciona como fechamento

**Sequência narrativa (45 segundos totais):**

```
Tração (Petrobras + TAM)        →  Valida que o mercado existe
    │
    ▼
ROI Defensável (47x-666x)        →  Valida que é viável economicamente
    │
    ▼
Urgência (Window 60→7 dias)      →  Cria pressão temporal
    │
    ▼
ASK (Piloto 90 dias)             →  Oferece ação concreta baixo-âncimo
```

**Atende os 4 critérios oficiais do SENAI:**

| Critério | Como esta session atende |
|---|---|
| **Aderência** | Petrobras + LGPD + ANP + 5 majors no SOM |
| **Criatividade** | Piloto 90 dias baixo-âncimo (vs 18 meses build custom) |
| **Qualidade Pitch** | Narrativa tração→ROI→urgência→CTA é linear e clara |
| **Atratividade** | ROI 47x-666x + payback < 1 dia + compliance multi-regulatório |

**Atende a regra do PI defensivo (`Rules_and_Winning_Strategies_GP.md` §4):**
- ROI mostrado como ordem de grandeza (47x), não breakdown exato
